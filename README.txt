Shaadi AI - APK banane ke steps
1. github.com par naya repository banayein (naam: shaadi-ai).
2. Is zip ko kholkar uske andar ki SAARI files/folders repository mein upload karein
   (.github folder bhi zaroor, wo chhupa hua folder hai).
3. Repository mein "Actions" tab kholein -> "Build APK" -> Run workflow.
4. 3-5 minute baad run ke andar "Artifacts" mein ShaadiAI-APK download karein.
5. Zip kholkar app-debug.apk phone mein install karein (Unknown sources allow karna padega).
